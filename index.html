DrugSupply Watch

An early-warning watchlist for new US drug shortages, built only from public FDA and Medicaid data. FDA doesn't publish its shortage history, so I rebuilt 12 years of it from about 460 Internet Archive captures of FDA's own page, keyed every drug to a stable ingredient, form and route, and tested the model year by year using only what was public at the time. Each week's predictions are frozen in public before the outcomes are known.

Top-100 list flags 1 in 4 new shortages a month early, vs 1 in 30 for random3,393 drug families trackedRuns nightly for $0

Python · logistic regression with exact per-drug reasons · walk-forward backtest · GitHub Actions · solo project

Live

StudyMatch

Places Penn State students into study groups of 4–5 from a short survey. A Gaussian mixture model finds study-style archetypes, then an integer program solved with OR-Tools CP-SAT assigns every student so that compatibility inside each group is as high as possible.

  1. Step 1Survey6-point Likert items with a consistency check
  2. Step 2ClusterGMM, number of archetypes chosen by BIC
  3. Step 3MatchCP-SAT integer program, groups of 4–5
  4. Step 4ServeFastAPI backend, vanilla JS frontend

Python · scikit-learn · OR-Tools · FastAPI · team project
